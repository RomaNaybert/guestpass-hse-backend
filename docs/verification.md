# Проверка реализации

Проверено 1 ноября 2026 года.

- Полный набор: 31 passed на Python 3.12 и отдельной PostgreSQL 16 в Docker.
- Ruff и синтаксическая проверка JavaScript: passed.
- Docker image: сборка успешна; API и PostgreSQL healthy, бот запущен с long polling.
- Через публичный HTTPS проверены подписанный Telegram initData, сессия в Authorization без cookie, распознавание настоящего PNG QR, начисление и повторное начисление. В журнале одна запись, 10 баллов.
- Внутренние маршруты извне закрыты. Доступ к карточкам требует проверенную Telegram-сессию и разрешённый контекст мероприятия.
- Проверка конкурентности: 24 запроса в 12 потоках дают одно начисление.
- Тестовые стенды проверяющих изолированы друг от друга и основной встречи.
- В браузере проверены вкладки камеры/фото/кода, состояние после начисления, мобильная компоновка и отсутствие ошибок JavaScript.

Ограничения проверки: физическая камера телефона и открытие Mini App на всех клиентах Telegram не проверялись. Распознавание фото проверено через API с PNG и JPEG. Производственная нагрузка в несколько тысяч одновременных подключений не измерялась. Для большого форума нужны мониторинг, лимиты запросов и отдельный нагрузочный прогон.

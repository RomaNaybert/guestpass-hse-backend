# Визуальные материалы

Выбранный референс — `design/reference-creative.png`, создан встроенным ImageGen по запросу для этого проекта. Предыдущий вариант сохранён как `design/reference.png`.

Отдельно тем же инструментом сгенерированы:

- `app/static/assets/scanner-ticket.png` — декоративный билет в зоне сканера;
- `app/static/assets/welcome-badge.png` — наклейка «ПРОХОДИТЕ!» с прозрачным фоном;
- `app/static/assets/paper-texture.png` — бумажная фактура.

Промпты элементов: `design/assets-prompts.md`. Изображение внутри сканера является иллюстрацией, а не действующим пропуском. PNG настоящих пропусков генерирует библиотека `qrcode`.

Иконки: **Phosphor Icons**, MIT License, https://github.com/phosphor-icons/core . Сохранены локально в `app/static/icons/`.

Шрифты: **Manrope** и **Roboto Condensed**, SIL Open Font License 1.1. Источники: https://github.com/google/fonts/tree/main/ofl/manrope и https://github.com/google/fonts/tree/main/ofl/robotocondensed . Сохранены локально в `app/static/fonts/`.

Тексты лицензий находятся в `app/static/licenses/`.
